# Kyla & Frend — Anniversary

## Jalankan
```
npm install
npm run dev
```
Buka alamat Network yang muncul di terminal dari HP (satu Wi-Fi dengan laptop).

## Deploy ke Netlify
Hubungkan repo GitHub ke Netlify. Build command `npm run build`, publish directory `dist` (sudah diatur di netlify.toml).

## Struktur
- src/components/Characters.jsx — koala dan kucing (mood happy/sad)
- src/components/OpeningScreen.jsx — animasi pembuka
- src/components/CodeForm.jsx — form kode 6 digit (251125)
- src/components/IntroScreen.jsx — placeholder Tahap 2
